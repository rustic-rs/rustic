# Documentation

Our documentation can be found at: <https://rustic.cli.rs/docs>

For unattended or otherwise important backups, see the
[operational production-readiness checklist](production-readiness.md). It is a
set of deployment checks, not a guarantee that a particular environment is
safe.

For `.gitignore` behavior while configuring a backup source, see
[Git ignore rules](gitignore.md).

For an rclone remote that works standalone but fails through rustic, see
[rclone backend troubleshooting](rclone.md).
